# SEALAI for Android

**[Download SEALAI.apk](https://github.com/breeiii/SEALAI-downloads/releases/latest/download/SEALAI.apk)**

Version **1.0.16** - Android **7.0 or later**. No GitHub account or sign-in is needed to download.

## Install on your phone

1. Open the download link using Wi-Fi or mobile data.
2. Download `SEALAI.apk`, then open it from Downloads.
3. If Android asks, allow your browser or file manager to install apps, then tap **Install**.
4. Open SEALAI and sign in to access your team's data, or select **Explore with demo data**.

This release updates official versions 1.0.1 through 1.0.15 using the same signing key. Install over the existing app to retain its data. If an older development build causes a signing conflict, export any needed local data before uninstalling that development build.

## What's new in 1.0.16

- **Session report stability fix**: Fixes a duplicate React key in the Survey Session detail view so all regression checks and live web deployments stay clean.
- **In-app Android updates (no browser needed)**: Retained from 1.0.15 — updates download directly inside SEALAI with a live progress bar, byte counter, Cancel option, SHA-256 and signing-certificate verification, and direct Android Package Installer launch.
- Preserves the Density heatmap / Individual sea cucumbers map dropdown, sub-meter specimen inspection, ecologically calibrated zoom-adaptive density heatmaps, survey names, GPS details, location filters, PDF exports, login, and device pairing.

Phones currently on version 1.0.15 can tap **Update now** inside SEALAI to install 1.0.16 without leaving the app. Phones on version 1.0.14 or earlier will download 1.0.16 once through the browser; every update after that installs right inside SEALAI.

Version 1.0.9 or later can show an in-app notice for this release when the app next checks for updates. Earlier versions need a manual download once to enable future notices. **Later** postpones reminders for that version for 24 hours. Android asks you to confirm installation.

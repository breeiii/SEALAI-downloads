# SEALAI for Android

**[Download SEALAI.apk](https://github.com/breeiii/SEALAI-downloads/releases/latest/download/SEALAI.apk)**

Version **1.0.10** - Android **7.0 or later**. No GitHub account or sign-in is needed to download.

## Install on your phone

1. Open the download link using Wi-Fi or mobile data.
2. Download `SEALAI.apk`, then open it from Downloads.
3. If Android asks, allow your browser or file manager to install apps, then tap **Install**.
4. Open SEALAI and sign in to access your team's data, or select **Explore with demo data**.

This release updates the official versions 1.0.1 through 1.0.9 using the same signing key. Install it over the existing app to retain its data. If an older development build causes a signing conflict, export any needed local data before uninstalling that development build.

## What's new in 1.0.10

- Refreshed login screens with SEALAI branding, an ocean-inspired design, clearer labeled fields, and light/dark styling.
- A centered theme icon and a labeled password visibility control.
- The account icon opens a dropdown with a separate **Log out** button. Opening the menu keeps you signed in.
- The account menu supports keyboard controls, outside clicks, Escape, and Android Back.
- Floating **Back to top** returns while scrolling every tab.
- Android update notices and previous survey, navigation, and security improvements remain included.

Version 1.0.9 users can receive an in-app notice for this update when the app next checks for releases.

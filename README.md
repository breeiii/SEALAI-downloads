# SEALAI for Android

**[Download SEALAI.apk](https://github.com/breeiii/SEALAI-downloads/releases/latest/download/SEALAI.apk)**

Version **1.0.3** - Android **7.0 or later**. No GitHub account or sign-in is needed to download.

## Install on your phone

1. Open the download link using Wi-Fi or mobile data.
2. Download `SEALAI.apk`, then open it from Downloads.
3. If Android asks, allow your browser or file manager to install apps, then tap **Install**.
4. Open SEALAI and sign in to access your team's data, or select **Explore with demo data**.

This release updates the official versions 1.0.1 and 1.0.2 using the same signing key. Install it over the existing app to retain its data. If an older development build causes a signing conflict, export any needed local data before uninstalling that development build.

Version 1.0.3 fixes known production dependency vulnerabilities, hardens Android backup and file sharing, and removes the two login-page taglines. It retains the animated SEALAI opening and reduced-motion support.

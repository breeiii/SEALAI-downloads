Version **1.0.9** - Android **7.0 or later**. No GitHub account or sign-in is needed to download.

## Install on your phone

1. Open the download link using Wi-Fi or mobile data.
2. Download `SEALAI.apk`, then open it from Downloads.
3. If Android asks, allow your browser or file manager to install apps, then tap **Install**.
4. Open SEALAI and sign in to access your team's data, or select **Explore with demo data**.

This release updates the official versions 1.0.1 through 1.0.8 using the same signing key. Install it over the existing app to retain its data. If an older development build causes a signing conflict, export any needed local data before uninstalling that development build.

Version 1.0.9 adds Android update notices and places **Back to top** at the bottom of Dashboard, Survey Summary, Survey Sessions, and Devices. When opened or resumed, the app checks for a newer published APK and offers **Download update** or **Later**. Later postpones reminders for that version for 24 hours. Offline checks stay quiet, and notices yield to open navigation and dialogs.

Install this release manually once to enable notices for future updates. Earlier versions cannot receive the feature remotely. Notices appear inside the app; downloading opens the official APK and Android asks you to confirm installation. There are no background push notifications or silent installations. Earlier navigation, phone layout, survey, and security improvements remain included.

# SEALAI for Android

**[Download SEALAI.apk](https://github.com/breeiii/SEALAI-downloads/releases/latest/download/SEALAI.apk)**

Version **1.0.13** - Android **7.0 or later**. No GitHub account or sign-in is needed to download.

## Install on your phone

1. Open the download link using Wi-Fi or mobile data.
2. Download `SEALAI.apk`, then open it from Downloads.
3. If Android asks, allow your browser or file manager to install apps, then tap **Install**.
4. Open SEALAI and sign in to access your team's data, or select **Explore with demo data**.

This release updates official versions 1.0.1 through 1.0.12 using the same signing key. Install over the existing app to retain its data. If an older development build causes a signing conflict, export any needed local data before uninstalling that development build.

## What's new in 1.0.13

- Survey names match across cards, results, galleries, search, and PDF downloads.
- Recorded GPS status, point counts, and latitude-first coordinates appear in results and PDFs. Individual maps focus on recorded locations.
- Invalid fixes are excluded; missing GPS and unconfigured device GPS sources are explained. Area estimates remain labeled separately.
- PDF reports include all recorded coordinates and page labels, and omit empty maps when GPS is unavailable.
- Existing location filters, species classifications, login, device pairing, dropdowns, navigation, and update notices remain included.

GPS requires measurements from the survey device. The app cannot reconstruct coordinates missing from an upload or configure kiosk firmware.

Version 1.0.9 or later can show an in-app notice for this release when the app next checks for updates. Earlier versions need a manual download once to enable future notices. **Download update** opens the official APK; **Later** postpones reminders for that version for 24 hours. Android asks you to confirm installation.

# SEALAI for Android

**[Download SEALAI.apk](https://github.com/breeiii/SEALAI-downloads/releases/latest/download/SEALAI.apk)**

Version **1.0.11** - Android **7.0 or later**. No GitHub account or sign-in is needed to download.

## Install on your phone

1. Open the download link using Wi-Fi or mobile data.
2. Download `SEALAI.apk`, then open it from Downloads.
3. If Android asks, allow your browser or file manager to install apps, then tap **Install**.
4. Open SEALAI and sign in to access your team's data, or select **Explore with demo data**.

This release updates official versions 1.0.1 through 1.0.10 using the same signing key. Install over the existing app to retain its data. If an older development build causes a signing conflict, export any needed local data before uninstalling that development build.

## What's new in 1.0.11

- **Back to top** fades and slides in when scrolling down, and animates out when returning to the top. Reduced-motion settings skip the animation.
- **Copy code** and **Download QR** have matching buttons; **Download setup file** has its own full-width row. Narrow phones stack the actions for readable labels.
- Survey location, region, site, and sort controls use dropdowns that match the app in light and dark themes.
- Dropdowns support keyboard navigation, type-ahead, outside clicks, Escape, and Android Back. Closing a dropdown keeps its parent dialog open.
- Header titles reserve space for account and theme controls on narrow phones.
- Earlier login styling, account dropdowns, surveys, and update notices remain included.

Version 1.0.9 or later can show an in-app notice for this release when the app next checks for updates. Earlier versions need a manual download once to enable future notices. **Download update** opens the official APK; **Later** postpones reminders for that version for 24 hours. Android asks you to confirm installation.
